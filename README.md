## Scientific and timing boundaries

The p=1.5 leading asymptotic cancellation and ra/a~0.466466787396 finite-energy local tangency are *previously explored*, not prospective predictions. Planned 20 coordinates are not verified historically held out. Certified sign classification requires independent implementation and justified numerical error bounds. Neither global phase-space positivity, dynamical stability, a new gravitational law, nor a direct Hydrus I star-by-star likelihood fit is claimed.
